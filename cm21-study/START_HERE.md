# How to use this with Codex

1. Start a Codex task with an accessible working environment. On Codex Cloud, start with a fork of the selected Umalator repo (ideally Andrew123Shi/Umalator) in your GitHub account. Publish the environment and start a task. In local Codex, clone the selected repo normally.
2. Upload/extract the `CM21_Codex_Handoff.zip` into the Codex task workspace (or pass the individual files), then ask Codex to open `CODEX_TASK.md` and carry out its investigation.
3. Our existing Python model/files are inside this archive and must not be mistaken for upstream game code.
4. Codex cloud tasks cannot automatically read sandbox paths from this chat. Upload the file into the Codex task or commit it to a private repo to grant access.
5. If Codex can't access a Windows executable, have it use the TypeScript source or run a browser build, and document constraints.

This bundle was prepared from the existing conversation artifacts; it does not contain an installed Umalator or claims of Umalator test runs.
